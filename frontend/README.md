## Tech Stack

- **Frontend**: Built with [SvelteKit](https://kit.svelte.dev/), utilizing [Skeleton](https://skeleton.dev/) for UI components and [Tailwind CSS](https://tailwindcss.com/) for styling.
- **Backend**: Implemented in [Golang](https://golang.org/).
- **App Bundling**: Uses [Tauri](https://tauri.app/) to package the application for distribution.
- **Development Server**: Uses [Vite](https://vitejs.dev/) for fast development builds.

## Development Guide

Ensure you have the following installed:
- **Node.js & npm**: Install from [Node.js official site](https://nodejs.org/).
- **Rust**: Install from [Rust official site](https://www.rust-lang.org/). _(macOS users should avoid Homebrew for this installation.)_
- **Git**: Install from [Git official site](https://git-scm.com/) if not already installed.
